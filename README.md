## 一、设计要求

用中小规模集成电路设计一台能显示日、时、秒的数字电子钟，要求实现可手动校时和整点报时，标准秒信号由晶振电路产生。

## 二、设计方案

整体可分为以下六个部分：秒脉冲发生器，六十进制秒、分计数器，二十四进制时计数器，译码显示，校时电路，整点报时电路。

核心逻辑是由晶振产生基准秒信号，通过分频得到标准信号，再通过逐级进位计数器实现“秒 → 分 → 时 → 周”的计时，最后通过译码数码管显示。校时电路和报时电路作为辅助功能并入系统。

## 三、模块设计

### 1. 秒脉冲发生器

由于暂未深入涉及晶振电路的硬件设计，在仿真阶段暂时采用函数信号发生器作为替代方案。能够稳定输出标准的秒脉冲信号，从而确保后续计时与控制功能的正常推进。

### 2. 计数器及显示

本系统的核心计数单元由7片74LS160构成，译码部分采用7片74LS47N译码器，并级联7个共阳极数码管进行时间显示。

**时钟脉冲与级联逻辑**：秒计数模块的时钟输入端直接接收函数发生器的标准秒脉冲。其余各级模块（分、时、周）均以上一级计数器产生的进位脉冲作为时钟基准，实现逐级递进的级联控制。

**进制的转换与实现**：74LS160为十进制计数器，当级联进制超过十进制时，需结合组合逻辑进行扩展。以分计数模块（六十进制）为例：设计采用两片74LS160级联，个位计数器的进位输出信号（RCO）直接接入十位计数器的使能端，用以控制十位的递增。

**清零控制**：可以由异步清零法和同步置数法两种方法实现，这里采用同步置数法。将两片74LS160的数据输入端全部接地；其数据输出端与74LS47N译码器相连，译码器输出端串联330Ω限流电阻后驱动数码管显示。以分计数模块为例，通过组合门电路从计数器输出端抽取“59”（0101 1001）这一特定状态，经与非门后接入个位和十位计数器的同步置数端。只有当个位有进位（使能端为1）与当前计数值为59（置数端为低电平0）这两个条件同时满足时，在下一个时钟脉冲到来瞬间，计数器才会同步复位归零，从而完整实现六十进制的循环计数。

### 3. 校时电路

校时电路的设计核心在于时钟源与控制信号的切换，具体分为两种工作状态：

- **正常计时**：后级计数器的时钟输入端接入前级计数器提供的进位信号，系统按正常时间逐级累加。
- **手动校时**：通过控制开关将后级计数器的时钟输入端切换至校时脉冲源。需要特别注意的是，针对十位计数单元，由于其使能端在正常状态下由个位进位信号控制，因此在切换至手动校时状态时，必须同步将十位的使能端改接至校时脉冲源。

### 4. 整点报时

- **低音报时**：分=59，秒=55、56、57、58、59，将相关信号通过组合逻辑电路（单独引出或4-10译码器）合并输出驱动蜂鸣器。
- **高音报时**：分=00，秒=00，将信号通过逻辑电路合并输出驱动蜂鸣器。

## 五、仿真结果

计时、显示、校时功能正常运行。  
整点报时异常，出现59分50秒也会响一声，没有找到原因。

## 六、总结与反思

本设计成功实现了基于74LS160和74LS47N的多功能数字电子钟。在设计过程中，深入理解了同步置数法在解决进制转换时的优势以及级联计数器的工作原理。

在设计和调试报时电路时，我遇到了一种非常奇特的现象：严格按照布尔逻辑推导的初版电路在仿真中结果恰好相反；而在盲目、尝试性地更改了一些电子元件、逻辑门类型后，仿真反而走向正常，但在理论逻辑上却完全说不通。

针对仿真中暴露的其他不足，后续的优化方向明确：  
一是针对仿真中出现的59分50秒误报，后续还需要继续排查；  
二是在硬件拓展层面，应引入石英晶振与CD4060分频电路以取代现有的函数发生器，从而大幅提升整个系统的独立性、精准度与实用价值。
